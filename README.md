# Staudenmaier Chiropractic Wellness Center

Marketing site for Staudenmaier Chiropractic Wellness Center, SC (Sturgeon Bay, WI).

- Production domain (planned): backwellness.org
- Content reference: https://www.backtowellness.org
- Stack: Next.js App Router, TypeScript, global CSS

## Local development

```bash
npm install
npm run dev
```

Scripts: dev, build, start, lint.

## Brand

BTW blues: #0c5284 / #1175bc / #007cba; neutrals #2c404e / #333; surfaces #f5f5f5 / #fafafa; accent #f7b733.

Clinic facts live in lib/site.ts. Do not invent claims, credentials, or patient quotes.
